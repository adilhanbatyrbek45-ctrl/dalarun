# Дала Run — Білім жолы

HTML, CSS және JavaScript тақырыптарына арналған қазақ тіліндегі шағын 3D runner. Үш жолақтың бірін таңдап, сұраққа жауап бер: әр дұрыс жауап **100 ұпай**, үш қате жауаптан кейін ойын аяқталады. Кедергілер жоқ.

## Құрылымы

- `index.html` — ойын интерфейсі
- `style.css` — көрініс және телефонға бейімделу
- `game.js` — 3D сахнасы, басқару және ойын ережелері
- `questions.json` — әр тақырыптан 50 сұрақ, барлығы 150

Үш өлшемді көрініс Three.js модулін jsDelivr CDN арқылы жүктейді. Сондықтан браузерде интернет қосулы болуы керек. Ойынның өзі серверді, дерекқорды немесе аккаунтты қажет етпейді.

## Жергілікті іске қосу

`index.html` файлын тікелей ашпай, жергілікті веб-сервер қолданыңыз. Модульдер мен JSON файлы сервер арқылы дұрыс жүктеледі.

Python орнатылған болса, жоба бумасында терминал ашып:

```bash
python -m http.server 8000
```

Содан кейін браузерден `http://localhost:8000/` мекенжайына өтіңіз.

## GitHub Pages-ке жариялау

1. GitHub-та жаңа репозиторий ашыңыз.
2. Осы буманың ішіндегі барлық файлды репозиторийдің негізгі (root) бумасына жүктеңіз: `index.html`, `style.css`, `game.js`, `questions.json`, `README.md`.
3. Репозиторийде **Settings → Pages** бөліміне өтіңіз.
4. **Build and deployment** бөлімінде **Deploy from a branch** таңдаңыз.
5. Branch ретінде `main`, бума ретінде `/ (root)` белгілеп, **Save** басыңыз.
6. Pages көрсеткен сайт сілтемесін ашыңыз. Алғашқы жариялануы біраз уақыт алуы мүмкін.

Файл сілтемелері салыстырмалы түрде берілген (`./...`), сондықтан жоба репозиторийдің түбірінен де, GitHub Pages ішкі жолынан да ашылады.

## Басқару

- Пернетақта: `←` / `→` немесе `A` / `D`
- Телефон: экранда солға/оңға сырғыту немесе төмендегі батырмалар
- `Esc` не `P`: ойынды кідірту немесе жалғастыру

Жауап нұсқалары экранның төменгі жағындағы үш жолаққа бекітілген. Таймер біткенде таңдалған жолақ жауап ретінде қабылданады.

## Сұрақтарды өңдеу

`questions.json` ішінде сұрақтар үш топқа бөлінген: `HTML`, `CSS`, `JavaScript`. Әр жазбада `question`, `correctAnswer`, `distractors` және `topic` өрістері бар. Әр тақырыпта 50 сұрақ болуы керек; бір сұрақта дұрыс жауап және екі қате нұсқа болуы қажет.

Қорда әр тақырыпқа 50 сұрақ болғандықтан, бір ойында әрқайсысы бір рет беріледі; тақырыптардың реті араласады. Ойыншылардың әр сессиясындағы жауап нұсқалары қайта араластырылады.
